# Echo dashboard design

## Scene and theme

A person setting up their assistant on a Mac in daylight, moving between familiar
services and wanting a clear next step. A light utility surface with a quiet green accent.

## Color

Restrained palette. Warm-green tinted background, near-white tinted surfaces,
dark green-gray text, a deep leaf-green action color. All tokens use OKLCH.
Provider monograms have distinct subdued brand-associated color treatments.

## Typography

Native system sans. 14px body, 12px utility labels, 16px section headings,
32px page title. Weight and spacing establish hierarchy, not decorative display fonts.

## Layout

208px sidebar, open main content, a searchable provider list, and an adjacent
connection detail panel. On narrow screens, navigation becomes horizontal and
the detail panel stacks above the list. No repeated feature-card grid.

## Components

Rounded compact buttons, full-width form controls, quiet dividers, labelled
status pills, provider monograms, inline errors, and a persistent connection flow
status. Connection details stay in the page rather than opening a modal.

## Motion

Brief color and opacity transitions. No decorative entrance animations.
Honor prefers-reduced-motion.
