# Product

## Register

product

## Users

Echo's owner uses their main macOS login to configure an always-on personal agent.
They want to connect their existing services without editing configuration files
or switching into the separate Messages login. They prefer direct, nontechnical UI.

## Product Purpose

Make the agent's account connections understandable and manageable. A successful
connection must be verified and immediately available to the actual agent.
Schedules and recent activity provide useful context alongside account setup.

## Brand Personality

Clear, calm, personal. Working visual default: a familiar Mac-like utility for a
daylit desktop, with simple forms and a searchable catalog. These are implementation
defaults, not a claim of user-confirmed brand research.

## Anti-references

Avoid a marketing landing page, developer-only JSON editors as the main experience,
decorative metrics, and integration tiles that imply an account is connected when it is not.

## Design Principles

- Connection state is evidence, not decoration.
- Explain the next step where the user needs it.
- Preserve existing connections and keep credentials on the owner's Mac.
- Use progressive details instead of interrupting ordinary setup with modals.
- Keep provider-specific requirements visible without exposing implementation noise.

## Accessibility & Inclusion

Use semantic controls, keyboard navigation, visible focus, readable contrast,
responsive layouts, text labels for status, and reduced-motion support.
